# Learning Rust

This repository contains my personal journey through [*The Rust Programming Language*](https://doc.rust-lang.org/book/), commonly known as *The Rust Book*. It includes code examples, exercises, and small experiments as I explore Rust's features and idioms.

## About

The Rust Book is the official introduction to the Rust programming language, covering concepts from the basics of ownership and borrowing to advanced features like lifetimes, traits, and concurrency.

This repository serves as:
- A personal learning log
- A place to experiment with Rust concepts
- A reference for others learning Rust

## Structure

The repository is organised (or will be) by chapter or topic from the book.
